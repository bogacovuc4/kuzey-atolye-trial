# Kuzey Atölye

Mimarlık ve iç mimarlık stüdyosu için tanıtım sitesi. Bağımlılığı olmayan statik HTML/CSS/JS.

- `index.html` — sayfa iskeleti
- `css/tokens.css` — renk, tipografi, boşluk token'ları
- `js/data.js` — tüm içerik
- `js/components.js` — tekrar kullanılan bileşenler
- `design-system/` — UI Pro Max tasarım sistemi kaydı

Yerelde çalıştırmak için `index.html` dosyasını açmanız yeterli.
